## ✦ About

<img align="right" width="260" src="assets/profile.jpg" alt="Adham Bassiouny" />

I'm a **Flutter developer from Egypt 🇪🇬** who builds fast, reliable, and good-looking mobile apps for Android and iOS from a single codebase.

I care about apps that are easy to use and code that's easy to maintain — so I build with **Clean Architecture**, keep state predictable with **Bloc & Cubit**, and connect everything to real backends through **REST APIs and Firebase**.

<br/>

🎯 &nbsp;**What I focus on**
- Scalable, testable app architecture
- Smooth UI and strong performance
- Clean, readable code that teams can build on

🌱 &nbsp;**Currently** — going deeper into advanced Flutter architecture and shipping my own apps to Google Play

💼 &nbsp;**Open to** — Flutter developer roles and freelance projects
